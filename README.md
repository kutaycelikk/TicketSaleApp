Overview
The E-Ticket Sale Application is a desktop-based software designed for purchasing and reserving tickets for various events and travels. Built with a focus on Object-Oriented Programming (OOP) principles and comprehensive UML architecture, it provides a seamless and user-friendly experience.

Key Features
User Authentication: Secure login and user registration system.
Interactive Seat Selection: Visual interface to check availability and select seats.
Ticket Booking: End-to-end process for reserving and purchasing tickets.
Order History: Allows users to view their past and current ticket reservations.
Technologies Used
Language: Java
GUI Framework: Java Swing
Design & Documentation: OOP Architecture, UML Diagrams
